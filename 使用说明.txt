ClaudeGuard - Claude 守护器 使用说明
=====================================

【它是干什么的】
启动 Claude 桌面版之前，先检查你的代理：
  1. 系统代理是否开启（默认 127.0.0.1:7890，可改）
  2. 代理端口能否正常握手
  3. 代理出口 IP 是否是约定的那个（首次使用时自己填）
全部通过才允许/自动启动 Claude；后台常驻托盘，每隔 15 秒复查一次，
一旦发现出口 IP 变了：立刻结束所有 Claude 进程 + 防火墙隔离 Claude 联网，
直到你切回正确节点，它会自动解除隔离。

【安装】（只需一次）
  1. 把 ClaudeGuard.exe 放到任意文件夹（建议固定位置）
  2. 右键 ClaudeGuard.exe → 以管理员身份运行
  3. 首次打开会出现引导向导，跟着走完三步（第 3 步选"安装到电脑"）
  4. 之后从桌面"ClaudeGuard"快捷方式启动即可（会自动请求管理员权限）

【要求】
  - Windows 10/11 64 位
  - 已安装 Claude 桌面版（Microsoft Store 版）
  - 代理客户端（如 Clash）已开启并设置为系统代理

【日常使用】
  - 主界面大圆环：绿色对勾 = 一切正常；红色感叹号 = 未通过；蓝色弧线 = 正在检查
  - "启动 Claude"按钮：只有检查通过时才会出现，点它会先复查再启动
  - "检查详情"可展开，看到底是哪一步出的问题（系统代理 / 端口 / 出口 IP）
  - "设置"里可改：代理端口、约定的出口 IP、检测间隔、是否自动杀进程/断网
  - 关窗口 = 最小化到托盘（后台继续守护）；托盘右键可退出
  - 开机自启默认关闭，可在设置里打开

【卸载】
  Windows 设置 → 应用 → 安装的应用 → Claude 守护器 → 卸载
  （会自动解除防火墙隔离并删除所有文件）

【文件位置】
  程序：%LOCALAPPDATA%\Programs\ClaudeGuard\ClaudeGuard.exe
  配置：%APPDATA%\ClaudeGuard\config.json
  日志：%APPDATA%\ClaudeGuard\guard.log

【常见问题】
  Q: 界面显示橙色"需要管理员权限"横幅？
  A: 自动断网（防火墙）需要管理员权限，请用快捷方式启动（会弹 UAC）。
  Q: 圆环是红色、提示"没有通过检查"？
  A: 说明出口不对或代理没连上，展开"检查详情"看哪一步出的问题；
     切回正确节点后点"重新检查"，通过后会自动解除隔离。
  Q: 想换端口/IP 要求？
  A: 主界面 → 设置 → 修改后保存即可。
  Q: 怎么升级新版本？
  A: 主界面会自动提示新版本，点"立即更新"即可（下载后自动替换并重启）；
     也可到 GitHub Releases 手动下载：
     https://github.com/daha1216/ClaudeGuard/releases
