用户指南
ClaudeGuard 是一个常驻后台的“网络守门员”：在使用 Claude 等 AI 桌面应用之前，先确认你的网络走的是约定的出口（代理 + 出口 IP/地区）。出口不对就立刻暂停这些应用并断开它们的联网，切回正确节点后自动恢复。

快速上手

  1. 第一次打开会出现引导向导，只需要填两个数字：
    • 代理端口：代理软件的 HTTP 端口（Clash 类常见是 7890）
    • 约定的出口 IP：从代理面板复制节点对应的出口 IP；可填多个，用逗号分隔，命中任意一个就放行
    • 没有固定 IP？出口地区选一个国家/地区，按地区放行
  2. 主界面出现绿色圆环「一切正常」，就表示网络走的是约定出口。
  3. 点「启动 Claude」即可正常使用。之后它在后台每 15 秒（可调）复查一次，不用管它。

主界面怎么看

绿色圆环 = 一切正常
出口与约定一致，点「启动 Claude」放心用。
红色圆环 = 已暂停守护对象
出口和约定不一致，已自动结束勾选应用的进程并断网。切回正确节点后下一次检查会自动恢复（解除断网），也可以点「我已切回节点，重新检查」立即恢复。
圆环下方状态行
守护状态、检查间隔、守护对象是否在运行（多进程显示 ×N）、是否检测到 CLI。
检查详情卡
代理 / 端口 / 出口三步各自的通过情况。
运行日志卡
最近 200 条检查与动作记录（绿色=通过，红色=异常）。

通用
  • 关窗后驻留托盘：窗口关掉后守护继续在后台跑；托盘图标右键可以彻底退出
  • 开机自启：需要先“安装到电脑”

托盘菜单（右键托盘图标）

显示主窗口 / 立即检测 / 暂停守护 30 分钟（检查照常，但不会结束进程或断网，到点自动恢复）/ 解除隔离 / 打开数据文件夹 / 退出

数据在哪里

  • 配置与日志：%APPDATA%\ClaudeGuard（主界面底部「打开数据文件夹」）
  • 卸载不会删除配置；想彻底清理就删掉上面这个文件夹

常见问题

Q：提示「需要管理员权限」？
自动断网要用防火墙规则，需要管理员。关掉窗口，右键桌面快捷方式“以管理员身份运行”即可。
Q：熔断后我切回了节点，怎么还没恢复？
等下一次自动检查（默认 15 秒），或点主按钮「我已切回节点，重新检查」。恢复是全自动的：进程可以重新打开，防火墙规则自动删除。
Q：检查一直显示“暂时没法确认网络”？
说明出口信息拿不到（代理没开 / 节点不通）。这种“信息不足”的情况不会熔断，宁可放行也不误杀。确认代理软件开着再点重新检查。
Q：更新怎么装？
设置卡底部「软件更新」会自动检查 GitHub Release；也可以直接下载新版安装包覆盖安装，配置都会保留。
