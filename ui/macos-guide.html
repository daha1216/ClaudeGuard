ClaudeGuard macOS 使用说明

检测代理出口，在出口异常时关闭选中的 AI 应用。

首次设置

  1. 将完整的 ClaudeGuard.app 放入“应用程序”文件夹，或在首次向导中选择“安装并继续”。已有版本时，请退出后再手动替换。
  2. 在设置中填写本机代理端口。守护器不会修改你的代理软件设置。
  3. 为启用的监控目标填写允许的 IP 或地区；两者任一命中即可通过。根据实际需要选择监控目标和守护应用。
  4. 保持“结束守护对象进程”开启，点击“立即检测”。从守护器启动 Claude 时，会再次检查全部启用目标。

异常时的行为

连续失败达到设置的阈值后，关闭选中的 AI 桌面应用，并禁止从守护器启动 Claude。出口恢复正常后解除限制，应用需手动启动。Claude 被选中时，熔断沿用原版行为，也会清理 Claude Code CLI。

这是进程守护模式。它保持整机网络连接，不是按应用防火墙；两次检测之间存在时间间隔。无法确认出口时不主动触发新的熔断，但也不允许从守护器启动 Claude。

暂停与恢复

暂停后不触发新的熔断；启动门禁仍会检测出口。手动“清除熔断状态”不会绕过启动前检测，也不会自动重新打开应用。

通知、自启与更新

通知测试需要在系统设置中允许 ClaudeGuard 通知。登录自启需要从“应用程序”文件夹中的完整应用启用。客户端自动更新默认关闭；启用后只在全部出口正常且客户端自行退出时安装官方签名更新，不强制关闭应用。

守护器自身自动更新需维护者提供签名发布包和内置发布公钥；当前本地预览尚未接入正式发布。

退出与数据

关闭窗口默认保留菜单栏守护；使用菜单栏“退出”或 Command-Q 结束程序。配置与日志位于 ~/Library/Application Support/ClaudeGuard。删除应用不会自动删除这些数据。飞书凭据经加密保存，密钥位于登录钥匙串。
