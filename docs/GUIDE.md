# ClaudeGuard 用户指南（v3）

ClaudeGuard 是常驻托盘的“网络出口门禁”：它按**每个目标自己的域名**分别检查出口，确认这些应用此刻走的是不是约定的那条链路、出口 IP / 地区是否在白名单里。全部通过才允许启动；任一启用目标不符合就立即熔断——结束相关进程、按开关做防火墙隔离，必要时直接断网；切回正确节点后自动恢复。

---

## 快速上手

1. 第一次打开会出现三步向导：
   - **代理端口**：代理软件的 HTTP 端口（Clash 类常见是 `7890`）。
   - **出口白名单**：填约定的出口 IP，可多个、逗号分隔；没有固定 IP 就选一个出口地区。期望值对**Claude / Codex** 两个目标生效。
   - **守护对象与开机自启**：勾选需要守护的桌面应用，决定是否随系统启动。
2. 主界面出现绿色圆环「守护正常」就表示各目标出口都符合约定。
3. 点「启动 Claude」即可使用。之后每 15 秒（可调）自动复查，不用管它。

## 主界面怎么看

- **绿色圆环 = 守护正常**：所有启用目标都通过，可以放心使用。
- **蓝色圆环 = 正在检查**：一轮探测进行中，目标行显示“待检测”。
- **红色圆环 = 已熔断**：有目标出口不符合约定（或启动被禁止）。熔断时会结束勾选应用的进程、按档位断网/隔离，切回正确节点后下一轮**自动恢复**；也可以在横幅上点「解除隔离」立即恢复。
- **灰色圆环 = 已暂停**：托盘里暂停了 30 分钟，期间照常检测但不会熔断。
- 每个目标一行：名称、结论（IP / 地区 / 可达）、出口 IP 与耗时；点底部的“详情”可以看到锚点地址与期望值。
- **详情卡**：每个目标的判定依据（锚点域名、期望 IP/地区）、运行参数（端口、间隔、防抖阈值、断网档位）、当前运行中的进程。
- **设置卡**：全部参数与监控目标管理。
- **日志卡**：最近 200 条检查与动作记录。

## 设置逐项说明

设置页按组折叠，同一时间只展开一组（点组头切换，默认展开「检测」）；组头右侧显示当前摘要，不展开也能看关键值。

**检测**

| 设置 | 说明 |
|---|---|
| 代理端口 | 系统代理指向的本地端口；探测默认跟随系统代理实际地址，读不到时才回退到它 |
| 检查间隔 | 每 N 秒复查一次，范围 5–3600（默认 15） |
| 立即重新检查 | 不等下一轮，马上跑一次 |
| 接入路径检查 | 系统代理没开且没有 TUN 网卡时，判定为「未接入」并按熔断阈值处理（防止 Claude 直连真实出口）；此状态下守护器自身也不直连探测（不暴露家宽 IP），开启 TUN 模式或系统代理即可解除 |

**判定的白名单**（对 Claude / Codex / 本机出口等目标共享）

| 设置 | 说明 |
|---|---|
| 出口 IP | 可填多个；命中任意一个放行 |
| 出口地区 | IP 不固定时按国家/地区放行（与 IP 是“或”的关系） |

> 某个目标的 IP 名单与地区**都为空**时，该目标永远不通过——这是刻意设计，避免没配规则时裸连。

**熔断与清理**（同一组）

| 设置 | 说明 |
|---|---|
| 断网档位 | `不断网` / `防火墙全局出站阻断`（默认，阻断全部出站流量，最快最稳）/ `禁用物理网卡`（更彻底，但会短暂断网卡） |
| 结束守护对象进程 | 熔断时结束勾选应用的全部进程 |
| 防火墙隔离 | 只拦截这些应用的网络（保留其它程序联网） |

两种“断网”与“隔离”可叠加使用；恢复时都会自动解除。

**进程清理**（同在「熔断与清理」组内）

| 设置 | 说明 |
|---|---|
| 退出后清理残留 | Claude 桌面端退出后，自动结束残留的桌面端子进程与“孤儿”CLI（父终端已关的 Claude Code）；桌面前台还在运行时绝不动作，宽限 4 秒防止误杀自动更新/快速重启 |

「清理 Claude 进程」一键按钮在**主界面「立即检测」旁边**：点一次变为红色「确认结束全部 Claude 进程？」，再点一次才会执行（3 秒内不确认自动复原）。

熔断时若守护对象含 Claude，Claude Code CLI 也会一并结束（Codex / Gemini CLI 仍只提醒不处理）。

**防火墙兜底封锁**（同在「熔断与清理」组内，v3.9）

| 设置 | 说明 |
|---|---|
| 未接入时自动封锁 | 系统代理和 TUN 都不在时，自动给守护对象的所有程序加防火墙出站 Block 规则——不连代理就出不去；走系统代理（127.0.0.1 回环）不受影响，接入后规则自动解除 |
| 一键封锁 / 解除 | 不等自动逻辑，立即手动封锁或解除（下一轮检查后自动逻辑按接入状态接管） |

说明：Windows 防火墙按程序（exe）拦截，等效覆盖该应用的全部域名；ClaudeGuard 会在需要时自动开启 Windows 防火墙（默认出站=允许，不影响其他软件正常联网），但绝不会替你关掉防火墙。

**守护对象**

- Claude 桌面版 / ChatGPT 桌面版 / 反重力桌面版：勾选哪些，熔断时就处理哪些。
- CLI 只提醒不处理：检测到 Claude Code / Codex CLI / Gemini CLI 在终端运行时只记日志提醒，**不会**杀终端进程。

**监控目标（可自定义）**

- 默认四个目标：`本机出口`（默认关闭）、`Claude 出口`、`Codex 出口`、`反重力出口`。
- 每个目标可改：名称、开关、探测地址（锚点）、期望 IP / 地区。
- 锚点支持四类：HTTP trace（如 `https://claude.ai/cdn-cgi/trace`，能读出精确 IP 与地区）、JSON IP 接口、Gemini 页面地区标记（`https://gemini.google.com` 读出 USA 类地区码）、仅可达性（HTTP 任意响应即算通）。
- 为什么反重力只测可达性：Google 后端域名没有 Cloudflare 的 trace 回显端点，拿不到出口 IP；只确认它连得上，避免误熔断。
- 为什么本机出口默认关闭：你的浏览器等常规流量通常走默认节点，出口 IP 与 AI 专用节点不同；默认开启会在第一次检查就熔断。需要监管本机出口时打开它，并把本机出口 IP 也加入白名单。

**通知与更新**

- 桌面通知六类：熔断、恢复、启动被阻止、失败预警、客户端更新、守护器更新提醒，可分别开关。
- **通知默认不含出口信息**：正文里不会出现出口 IP 与地区（打码为「已隐藏」）。需要看具体出口时，打开设置里的「通知附带出口信息」；关闭状态适合会转发通知或截图分享的场景。
- 飞书群通知：群机器人 Webhook（可加签名密钥），凭据用 Windows DPAPI 加密；正文同样默认脱敏。
- Claude / Codex 客户端更新：默认关闭，开启后每周检查一次，也可手动检查；只在官方 MSIX 源下载并校验签名后原位升级。
- 守护器自身更新：默认每 6 小时在后台静默检查 GitHub Releases，发现新版本弹桌面通知（同一版本只提醒一次）；也可在设置中手动检查、一键下载升级。下载后按官方 SHA-256 摘要校验，摘要缺失或校验不符会取消更新；熔断、封锁或停止保护期间不执行更新。
- 关闭到托盘 / 开机自启。

## 托盘菜单（右键托盘图标）

显示主窗口 / 立即检测 / **暂停守护 30 分钟**（再次点击恢复，暂停期间照常检测但不熔断）/ **解除隔离并恢复网络** / 打开数据文件夹 / 退出。

## 数据在哪里

- 配置与日志：`%APPDATA%\ClaudeGuard`（设置卡 → 通用 → 数据文件夹 → 打开）
- `config.json` 配置、`guard.log` 日志、`netcut.json` 断网现场（用于崩溃后自愈）、`feishu.json` 通知、`claude-update.json` / `codex-update.json` 客户端更新状态。
- 卸载不会删除这些文件；想彻底清理就删掉整个文件夹。

## 常见问题

**Q：提示「需要管理员权限」？**
防火墙隔离、断网档位、客户端原位升级都需要管理员权限。关掉窗口，右键快捷方式“以管理员身份运行”。

**Q：熔断了，我切回节点后怎么还没恢复？**
等下一轮自动检查（默认 15 秒），或点横幅上的「解除隔离」，或托盘里「解除隔离并恢复网络」。恢复是全自动的：进程可重新打开、防火墙规则与断网规则都会删除。

**Q：检查显示「无法确认」/「未验证」？**
说明探测拿不到信息（代理没开、节点不通、锚点被墙）。这种“信息不足”的情况**不会**熔断；确认代理开着再点重新检查。

**Q：整个电脑断网了怎么办？**
说明熔断档位是 `防火墙全局出站阻断` 或 `禁用物理网卡`。最省事的办法：托盘「解除隔离并恢复网络」；如果窗口都打不开，运行 `ClaudeGuard.exe --restore`（管理员）急救。正常退出程序时也会自动恢复。

**Q：本机出口目标一直是红的？**
你的常规流量出口与白名单不一致。把本机出口 IP 加进白名单，或者在设置里关闭“本机出口”目标。

**Q：能同时守护 ChatGPT / 反重力吗？**
可以，在设置 → 守护对象里勾选；它们各自按自己的目标判定，互不牵连。
